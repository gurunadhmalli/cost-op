## 2. Page Specifications & Wireframe Models

### 2.1 Surface 1: Command Center (`DashboardPage.tsx`)
- **Header**: Live Facility KPIs (Actual Cost/Unit, Baseline Cost/Unit, Cost Variance %, Verified QTD Savings ₹, Open Anomalies, Shop OEE %).
- **Middle Grid (2-Column)**:
  - Left (60%): `CostTrendChart` (Composed Area/Line chart of actual vs 90-day baseline).
  - Right (40%): `ABCBreakdownChart` (Donut chart splitting cost into Material, Energy, Labor, Overhead).
- **Lower Grid (2-Column)**:
  - Left (55%): `AssetLiveGrid` (Live machine telemetry with power, temp, pressure, vibration, OEE).
  - Right (45%): `QuickActionRadar` (Top ranked recommendations with projected quarterly savings and 1-click implement button).

### 2.2 Surface 2: Anomaly Radar (`AnomaliesPage.tsx`)
- **Filters**: Severity (`High`, `Medium`, `Low`), Status (`Open`, `Investigating`, `Resolved`), Metric (`energy_kwh`, `temperature_c`, `pressure_bar`).
- **Telemetry Timeline**: Time-series chart showing upper/lower baseline confidence bands, actual readings, and red alert markers.
- **Data Table**: Columns for Asset ID, Machine Name, Metric, Deviation %, IsoForest Anomaly Score (0.00–1.00), Daily Cost Impact (₹ / $), and direct `Root Cause AI` button.

### 2.3 Surface 3: Root Cause Studio (`RootCausePage.tsx`)
- **4-Level Drilldown Breadcrumb**: `Plant (Pune)` &rarr; `Line (Line 03)` &rarr; `Machine (Extruder 3A)` &rarr; `Skipped Chiller Filter (Overdue 14 days)`.
- **SHAP Feature Attribution Waterfall**: Ranked horizontal bars showing Shapley value additions to baseline cost.
- **Weighted Confidence Breakdown**:
  - Correlation Strength ($r = 0.79 \rightarrow 50\%$)
  - Historical Diagnostic Accuracy ($94\% \rightarrow 30\%$)
  - Sensor Telemetry Completeness ($98\% \rightarrow 20\%$)
  - **Overall Confidence**: **87.0%**
- **Natural Language Diagnostic Card**: Auto-generated by Google Gemini API function calling.

### 2.4 Surface 4: What-If Optimization Sandbox (`WhatIfPage.tsx`)
- **Interactive Action Sliders**:
  - Parameter 1: Setpoint Reduction (-1°C to -10°C)
  - Parameter 2: Shift Reschedule to Off-Peak TOU Tariff Window
  - Parameter 3: Maintenance Filter Cartridge Swap
- **PuLP / OR-Tools Optimization Solver Table**:
  - Action Name
  - Estimated Implementation Cost (₹ / $)
  - Downtime Hours (h)
  - Projected Quarterly Savings (₹ / $)
  - Payback Period (Days)
  - Feasibility Badge (`Feasible` vs `Violates Production Constraint`)
  - ROI Rank (1 to 4)

### 2.5 Surface 5: Gemini AI Co-Pilot (`CoPilotPage.tsx` & `ChatDrawer.tsx`)
- **Conversational Interface**: Natural language question answering with streaming responses.
- **Function Calling Diagnostics**: Visual pill showing tool execution (`Calling get_anomalies(line_id="LINE-03")...`).
- **Embedded Evidence Cards**:
  - Root Cause Summary
  - Confidence Dial
  - One-Click `Mark Implemented` Action Button

### 2.6 Surface 6: Closed-Loop Action Tracker (`ActionTrackerPage.tsx`)
- **Lifecycle Kanban**:
  - Column 1: `Open Recommendations`
  - Column 2: `Implemented (Pending 7-Day Verification)`
  - Column 3: `Verified & Recalibrated`
- **7-Day Verification Countdown**: Live timer ticking down to `kpi_remeasure_dag.py` execution.
- **ROI Impact Variance**: Comparison of projected savings vs actual verified savings (e.g. Projected ₹1.45L vs Verified ₹1.52L &rarr; +5.1% efficiency).

### 2.7 Surface 7: Activity-Based Cost Reports (`ReportsPage.tsx`)
- **Tabular Report**: Cost breakdown per Plant, Line, Shift, and SKU.
- **Export Capabilities**: 1-click CSV and PDF export.

## 3. Core Component Implementation Code Reference

### 3.1 Root Cause SHAP Component (`SHAPWaterfall.tsx`)
```tsx
export const SHAPWaterfall: React.FC<{ drivers: SHAPDriver[] }> = ({ drivers }) => {
  return (
    <div className="space-y-4">
      {drivers.map((d, i) => (
        <div key={i} className="rounded-xl border border-slate-800 bg-industrial-900/60 p-4">
          <div className="flex justify-between">
            <h4 className="font-semibold text-white">{d.driver}</h4>
            <span className="font-mono text-rose-400 font-bold">+{d.contributionPct}% Impact</span>
          </div>
          <div className="mt-2 h-2 w-full rounded-full bg-industrial-850 overflow-hidden">
            <div className="h-full bg-gradient-to-r from-cyan-500 to-rose-500" style={{ width: `${d.contributionPct}%` }} />
          </div>
          <div className="mt-2 text-xs font-mono text-cyan-300">
            Fix: {d.recommendedFix}
          </div>
        </div>
      ))}
    </div>
  );
};
```

### 3.2 What-If Scenario Matrix (`OptimizationMatrix.tsx`)
```tsx
export const OptimizationMatrix: React.FC<{ scenarios: WhatIfCandidateAction[] }> = ({ scenarios }) => {
  return (
    <div className="overflow-x-auto">
      <table className="w-full text-xs font-mono">
        <thead>
          <tr className="border-b border-slate-800 text-slate-400">
            <th>Rank</th>
            <th>Candidate Action</th>
            <th>Cost</th>
            <th>Downtime</th>
            <th>Projected Savings</th>
            <th>Payback</th>
            <th>Feasibility</th>
          </tr>
        </thead>
        <tbody>
          {scenarios.map((s) => (
            <tr key={s.id} className="border-b border-slate-800/60">
              <td className="font-bold text-cyan-400">#{s.rank}</td>
              <td className="text-white font-sans">{s.action}</td>
              <td>₹{s.estimatedCost}</td>
              <td>{s.downtimeHours}h</td>
              <td className="text-emerald-400 font-bold">₹{s.projectedSavingsQuarter.toLocaleString()}</td>
              <td>{s.paybackDays} days</td>
              <td>
                <span className={s.feasible ? 'text-emerald-400' : 'text-rose-400'}>
                  {s.feasible ? 'Feasible' : 'Constraint Breach'}
                </span>
              </td>
            </tr>
          ))}
        </tbody>
      </table>
    </div>
  );
};
```
